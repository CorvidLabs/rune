# Research

The SDD evaluator applies ignored paths broadly enough that `.specsync/` shadows explicit meaningful
policy entries. Existing publish validation proves tag existence and ancestry but does not enforce
the documented prefix. Attest records are commit-addressed, so a merge commit must be signed before
the trust gate evaluates that commit.
